### 🚀 DeX Launcher v0.1.0-pre (Initial Pre-Release)

Samsung DeX-inspired desktop launcher for Android & HarmonyOS tablets (optimized for HUAWEI MatePad Air).

#### ✨ Fitur Unggulan:
- 🖥️ **Samsung DeX Inspired Interface:** Taskbar di bawah dengan tombol Start, Pinned Apps, dan System Tray.
- 🦀 **Rust Core Native Engine:** Fuzzy search aplikasi super cepat via JNI bindings (`dex_core`).
- 🎨 **Kustomisasi Icon:** Mendukung bentuk *Squircle*, *Circle*, *Rounded*, *Teardrop*, penyesuaian ukuran icon slider (40-72dp), dan sembunyikan/tampilkan label.
- 🪟 **Floating Windows Native HarmonyOS:** Menghormati manajemen multi-window dan sidebar dock bawaan Huawei tanpa konflik.
- 🔋 **Live System Tray:** Status baterai real-time, indikator WiFi/Jaringan, dan jam digital.

#### 📦 Panduan Instalasi di Tablet:
1. Unduh berkas `dex-launcher-v0.1.0-pre.apk` di bawah ini.
2. Buka dan instal di tablet Anda (izinkan pemasangan dari sumber tidak dikenal jika diminta).
3. Masuk ke **Pengaturan** > **Aplikasi** > **Aplikasi Standar** > **Beranda / Peluncur** > Pilih **DeX Launcher**.
