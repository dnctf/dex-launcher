# 🎉 DeX Launcher (Soda Bottle Edition)

A lightweight Android home launcher that mimics Samsung DeX UI, now with a custom **soda‑bottle** app icon.

## Features
- Centered task‑bar with pinned apps and system tray (clock, battery, Wi‑Fi).
- Settings panel for wallpaper, icon size, shape, grid columns and label toggle.
- Built‑in widget manager (placeholder for future widgets).
- All apps launch in free‑form windows on HarmonyOS/Android 12+.

## Installation
1. Download the latest APK from the **Releases** page.
2. Install and set as the default Home app in your device settings.

*Enjoy a clean, DeX‑style experience on your tablet!*
